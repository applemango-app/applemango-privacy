애플망고(Apple Mango) 개인정보처리방침

시행일: 2026년 10월 30일 (이전 버전: 2026년 10월 8일, 2026년 9월 22일)

애플망고(이하 "본 앱")는 초·중등 교사가 학생 평가 및 관찰 기록을 관리하기 위한 개인용 도구입니다. 본 방침은 본 앱이 어떤 정보를 다루고, 어떻게 보관하며, 외부로 전송되는 경우가 있는지를 설명합니다.

1. 수집하는 정보와 저장 위치

본 앱은 교사가 입력한 데이터를 보관하는 서버를 운영하지 않습니다. 아래 정보는 모두 사용자의 기기 안에 저장되며, 개발자를 포함한 어느 누구도 서버를 통해 조회할 수 없습니다. (교사가 PC 버전을 켠 경우에는 4항에 따라 교사 본인의 구글 드라이브에 암호화된 사본이 함께 저장됩니다.)

  • 교사가 입력한 학생 이름, 학급/번호, 평가 결과, 성취수준, 관찰 기록(누가기록) 등 — 기기 내 로컬 데이터베이스(SQLite)에 저장
  • AI 기능 이용 시 입력하는 API 키 — 기기 내 보안 저장소(Android Keystore 기반 SecureStore)에 저장
  • 알림 예약을 위한 채점 일정 정보 — 기기 내 로컬 알림(OS 알림 기능)으로만 사용

앱을 삭제하면 위 데이터는 기기에서 함께 삭제됩니다. 교사가 PC 버전(4항)을 켜지 않는 한 클라우드에 자동으로 저장되지 않으며, 교사가 직접 "백업" 또는 "엑셀로 내보내기" 기능을 실행한 경우에만 파일이 생성되고, 그 파일을 어디로 공유할지는 전적으로 교사가 결정합니다. 위 정보와 별개로, 학생·기록 내용이 포함되지 않은 익명 사용 통계만 3항에 따라 전송되며 설정에서 끌 수 있습니다.

2. 제3자 AI 서비스로 전송되는 정보 (선택 기능)

본 앱은 관찰 기록·평가 결과를 바탕으로 생활기록부 문구를 자동 생성해주는 선택적 AI 기능을 제공합니다. 이 기능은 교사가 직접 API 키를 입력하고 실행을 눌렀을 때만 동작하며, 이 경우에 한해 입력된 텍스트가 교사가 선택한 아래 AI 제공업체 중 하나로 전송됩니다.

제공업체전송되는 정보제공업체 개인정보처리방침
Google (Gemini)관찰 기록/평가 결과 텍스트policies.google.com/privacy
Anthropic (Claude)관찰 기록/평가 결과 텍스트anthropic.com/legal/privacy
OpenAI관찰 기록/평가 결과 텍스트openai.com/policies/privacy-policy

처음 AI로 보내기 전에 교사의 동의를 받으며, 동의는 설정에서 언제든 철회할 수 있습니다. 앱은 보내기 전에 기록 속 학급 학생들의 이름을 가려 "학생" 등으로 바꾸고, 프롬프트에도 "학생 이름 등 식별 정보를 포함하지 말 것"을 지시합니다. 다만 이름 외의 내용은 교사가 작성한 그대로 전송되므로 학생을 특정할 수 있는 표현(주소, 별명, 가족 사항 등)을 직접 기록하지 않도록 주의하시기 바랍니다. 이 기능을 사용하지 않으면 어떤 정보도 외부로 전송되지 않습니다. API 키는 개발자 서버를 거치지 않고 기기에서 각 제공업체로 직접 전달되며, 개발자는 이 통신 내용을 볼 수 없습니다.

앱을 개선하기 위해, 어떤 기능을 몇 번 사용했는지와 앱 오류 정보를 미국의 분석 서비스 PostHog로 보냅니다. 이 정보로는 사용자나 학생을 알아볼 수 없으며, 설정 화면의 "사용 통계 보내기"를 끄면 즉시 전송이 중단됩니다.

· 학교·학급·평가계획 이름, 교사 이름, 비밀번호, API 키

4. PC 버전 사용 시 (선택 기능, 구글 드라이브)

교사가 설정에서 "PC 버전 사용"을 켜면, 폰과 PC 브라우저에서 같은 데이터를 쓰도록 앱 데이터를 교사 본인의 구글 드라이브에 저장합니다. 이 기능을 켜지 않으면 아래 내용은 적용되지 않습니다.

  • 저장 위치: 교사 구글 드라이브의 "앱 전용 숨김 폴더"(appDataFolder). 본 앱은 이 폴더만 볼 수 있고 드라이브의 다른 파일은 볼 수 없습니다. 요청하는 권한은 이 폴더 하나(drive.appdata)뿐입니다.
  • 저장되는 내용: 1항의 앱 데이터(API 키 제외)를 암호화한 사본과 그 암호를 푸는 열쇠. 개발자는 이 폴더에 접근할 수 없습니다.
  • 로그인 유지 서버: PC 브라우저가 구글 연결을 매시간 다시 하지 않도록, 개발자가 운영하는 작은 서버(Cloudflare Workers)가 구글 로그인 열쇠를 새로 받아 주는 일만 합니다. 이 서버는 교사의 데이터나 구글 계정 정보를 저장하지 않으며, 다시 받기용 열쇠는 잠긴 상태로 교사의 브라우저에만 보관됩니다.
  • 끄기·삭제: 폰에서 "PC 버전 사용"을 끄면 드라이브의 사본이 삭제됩니다. 구글 계정 설정(myaccount.google.com → 보안 → 타사 앱 연결)에서 애플망고 연결을 해제할 수도 있습니다.

본 앱이 구글 API로 받은 정보의 사용과 다른 앱으로의 전송은 Google API 서비스 사용자 데이터 정책(제한적 사용 요구사항 포함)을 따릅니다. 드라이브 데이터는 폰과 PC 사이의 동기화에만 쓰이며, 광고나 AI 학습 등 다른 용도로 쓰거나 제3자에게 제공하지 않습니다.

5. 권한 사용 목적

  • 정확한 알람(SCHEDULE_EXACT_ALARM): 설정한 시각에 채점 마감 알림을 정확히 보내기 위함
  • 알림(POST_NOTIFICATIONS): 채점 관련 알림을 표시하기 위함
  • 생체인증(Face ID/지문): 앱 잠금 해제 용도로만 사용되며, 인증 정보는 OS가 처리하고 본 앱은 결과(성공/실패)만 전달받습니다.

6. 아동의 개인정보

본 앱은 학생이 아닌 교사가 사용하는 업무 도구입니다. 학생은 본 앱을 직접 설치하거나 사용하지 않으며, 학생 관련 정보는 교사가 업무 목적으로 직접 입력·관리합니다.

7. 계정 및 데이터 삭제 방법 (애플망고)

애플망고는 별도의 서버 계정이 없으므로, "계정 삭제"는 곧 기기에 저장된 앱 데이터를 지우는 것과 같습니다. 아래 방법 중 하나를 이용하실 수 있습니다.

  • 일부 데이터만 삭제: 앱 실행 → 설정 화면 → 원하는 학생/평가/기록을 선택해 개별 삭제, 또는 "채점 일괄 취소" 기능으로 특정 평가의 모든 채점 결과를 한 번에 삭제할 수 있습니다.
  • 앱 안에서 전체 삭제: 설정 화면의 "모든 데이터 삭제"를 누르면 기기에 저장된 모든 앱 데이터가 지워지고 처음 화면으로 돌아갑니다.
  • 전체 데이터(계정) 삭제: 기기에서 애플망고 앱을 삭제(제거)하면 이름, 학급 정보, 평가 결과, 관찰 기록, API 키 등 앱이 저장한 모든 데이터가 즉시, 영구적으로 삭제됩니다.

삭제 요청 처리를 위해 개발자에게 연락하실 필요는 없습니다(모든 데이터가 기기에만 있어 개발자는 애초에 접근할 수 없습니다). 교사가 입력한 데이터는 개발자의 어떤 서버에도 보관되지 않습니다. PC 버전을 켠 경우의 드라이브 사본은 4항의 방법으로 삭제할 수 있습니다. 3항의 익명 사용 통계는 사용자를 알아볼 수 없어 개별 삭제 대상을 특정할 수 없으며, 앱을 삭제하면 무작위 번호도 함께 사라져 이후로는 연결되지 않습니다. 또한 백업 파일을 직접 만들어 공유한 경우에는 그 사본까지는 본 방침이 통제할 수 없으니 별도로 삭제해 주세요.
